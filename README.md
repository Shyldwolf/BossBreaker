# BossBreaker (DPS Calculator) ⚔️📊

**BossBreaker** is a lightweight **Python CLI** tool to calculate and compare **DPS (damage per second)** for different towers/builds and quickly evaluate which setup performs better.

---

## ✨ Features
- Simple command-line flow
- Fast DPS calculations
- Input validation + basic error handling
- Easy to extend with presets, exports, or a UI

---

## 🧰 Tech Stack
- **Python**
